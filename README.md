# Second Play

A shop for selling my pre-loved toys. Anyone with the link can browse, add toys to a cart and send the order on WhatsApp.

- `index.html`: the shop
- `toys.json`: the toys and shop settings (the shop updates this file for you)
- `photos/`: toy photos (created automatically when you add the first photo)

To sell: open the site, tap **Seller sign-in** at the bottom, paste your GitHub token, then tap **Seller** and use **+ Add a toy**.
